# 컴퓨터 학습에 나온 베이직 팽귄 게임

오래전 어렸을적, 1985년 12월호 컴퓨터 학습에 나온 게임을 보고 한번 넣어서 해보고 싶었습니다. 그리고 코드 분석도 하며 공부도 할겸입니다. 세월이 지나 잊혀졌다 다시 생각이 났습니다. 이 리포는 그것에 대한 기록입니다.

밑의 글은 네이버 카페에 2022년9월22일에 올린것입니다. https://naver.me/FFqLg60R

# 본문

컴학 85년 12월호에 나온것입니다. 80년도 후반에 미국에 오면서 컴퓨터 책 몇권 가지고 왔는데, 아마도 한 90년도 중반에 쯤? 짐이 많아져서 버린듯합니다. 그때 맥오리지널도 같이 버렸어요. ㅠㅠ

여튼 그때 가끔 기사를 보면서 언젠가는 해봐야지... 했어요, 그 팽귄게임이 오락실에서도 있었잖아요, 그때 참 재밌게 했었죠. (팽귄이 얼음 블락을 밀어서 적들을 죽이는..)

OCR로 대충 화일로 만들고, 텍스트 에디터로 기사를 보면서 잘못된곳을 고쳤습니다. 1과 대문자 i가 제대로 OCR안되었고, 저역시 기사가 흐릿해서 못보고 지나친것이 나중에 프로그램이 제대로 안돌아가서 분석겸, 체크겸 한줄 한줄 다 보면서 코멘트도 더 넣고 했습니다.

이게 오리지널이 어디서 나온걸까... 궁금해서 찾아봤지만, 86년10월호의 외국의 잡지에서 나온것 밖에 없습니다. 소스는 거의 일치합니다. https://archive.org/details/applicando030

일단 게임분석이니 게임나온부분들만 첨부하겠습니다:
- 컴학: [penguin.pdf](docs/penguin.pdf)
- 다른 외국잡지: [penguin-other.pdf](docs/penguin-other.pdf)

여기서 질문을 올려서 알은것: 
베이직 프로그램은, 이렇게 저장합니다.

`] SAVE PENGUIN`

기계어 부분은 이렇게 넣습니다.

```
] CALL-151
* 0900: 04 00 0A 00 3D 00 70 00
```

... 이렇게 넣은 다음 ...

```
* 3D0G
] BSAVE PENGUIN.SHAPES, A$900, L$D6 
```

소스코드와 기계어(데이타) 부분을 텍스트 화일로 첨부합니다: 
- [penguin.bas](src/penguin.bas)
- [penguin-shape.txt](src/penguin-shape.txt)

Notepad++ 에서 열은후 전체선택, COPY 한후에, AppleWin에서 SHIFT + INSERT 로 PASTE가 됩니다.

DOS 3.3 디스크를 사용해서 위의 화일들을 저장했습니다: [penguin.dsk](penguin.dsk)
